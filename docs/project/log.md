## 日志文档

日志存储在根目录的 `\log` 目录下。url 存储完整地址。

## `dispatch.log` —— 派发流水

负责：每一次向下游转发用户命令的记录。

字段：`ISO8601时间 程序id 程序名 接口id 接口名 消息类型 下游url HTTP状态码 业务状态码`

- 两个状态码为下游返回的
- 若下游未返回状态则`ISO8601时间 程序id 程序名 接口id 接口名 消息类型 下游url 发送失败`

## `send.log` —— 发送流水

负责：下游调用本层发送接口的每次记录。

字段：`ISO8601时间 程序id 程序名 用户id 消息类型 下游url HTTP状态码 业务状态码`

- 两个状态码为本层回给下游的

## `feishu.log` —— 飞书流水

负责：每次对飞书 API 实际调用的记录；发一个文件记两行（上传+发送）。

发送字段：`ISO8601时间 程序名 飞书接口url 目标用户id HTTP状态码 业务码`
接收字段：`ISO8601时间 用户id`

- HTTP 状态码与业务码，是为飞书返回的而非本程序的

## `registry.log` —— 注册流水

负责：程序的注册与心跳超时清除记录。

字段：

- `register` 行：`ISO8601时间 事件 程序id 程序名 base_url 接口id 接口名`
- `dead` 行：`ISO8601时间 事件 程序id 程序名 base_url 接口数`

- 事件两种：`register` 注册 / `dead` 心跳超时清除
